# 性格与说话方式分析指南

目标不是写一篇人物小传，而是让模型读完 `persona` 和 `style_samples` 之后，在博客评论区说出 TA 会说的话。所以每一条结论都要能落到「会说什么、怎么说、什么时候说、什么时候不说」上。

## 1. 先看数据

```bash
python3 scripts/style_stats.py distill-<id>/corpus/self.txt
python3 scripts/active_hours.py distill-<id>/corpus/timestamps.txt --tz <IANA 时区>
```

`style_stats.py` 给出：消息长度分布、句末标点分布、常见标点与符号的使用率、语气词和网络用语的频率、emoji 与颜文字的使用率、中英混用比例、反复出现的短语（口头禅候选）。

`active_hours.py` 给出：按小时的活跃直方图、建议的 `active_hours`、工作日与周末的活跃比（建议的 `weekend_factor`）、时间戳中出现的时区偏移（帮助确认 `timezone`）。

脚本只是统计，结论要自己判断：

- 数据按来源分开看。代码评论、长文、聊天、社交动态的风格往往不同，博客评论最接近社交平台上的回复。
- 「每条消息都用」和「偶尔用」差别很大。记录频率，写进 persona 时用「几乎每条」「经常」「偶尔」「很少」并尽量给出比例。
- 注意 TA **不做**的事：从不用感叹号、从不用 emoji、从不说「大佬」，这些和做的事一样有辨识度。

## 2. 说话方式指纹

逐项填写，每项给 2～3 条原话为证：

| 维度 | 要回答的问题 |
| --- | --- |
| 长度 | 一条通常多少字？习惯连发几条短的，还是一条说完？ |
| 句末 | 用不用句号？常以什么结尾（语气词、波浪号、表情、什么都不加）？ |
| 标点与符号 | 感叹号、问号、省略号（`…` `...` `。。。`）、波浪号 `～`、空格断句、全角半角混用 |
| 语气词与网络用语 | 哈哈 / hhh / 233 / 草 / 笑死 / 确实 / 好家伙 / 绝了 / 捏 / 嘛 / 呢 / 吧，各自的频率 |
| 表情 | emoji、颜文字、表情包的种类与频率，常用的是哪几个 |
| 中英混用 | 英文单词、缩写（yyds、xswl、LGTM、IMO）、技术术语的密度 |
| 称呼 | 怎么称呼别人（你、大佬、老师、哥、bro、直接叫 ID） |
| 句式 | 常用的开头（「其实」「我觉得」「讲道理」）和句式（反问、设问、列点） |
| 赞同 / 反对 | 赞同时怎么说（「+1」「确实」「好耶」），反对时直接还是委婉，会不会先肯定再补充 |
| 错别字与谐音梗 | 是刻意的风格还是手滑？刻意的才写进 persona |

## 3. 性格

- **大五人格**：开放性、尽责性、外向性、宜人性、情绪稳定性各给出 低 / 中 / 高 与证据。只作为辅助，最终要翻译成行为描述（例如「宜人性高」→「很少直接反驳，不同意时会说『我这边的情况不太一样』」）。
- **沟通风格**：直接还是委婉，讲道理还是玩梗，会不会主动关心人，会不会好为人师。
- **典型反应**：被夸、被批评、遇到不同意见、遇到新手提问、遇到争议话题时分别怎么回应。
- **幽默**：冷笑话、自嘲、吐槽、反讽、玩梗，或者基本不开玩笑。
- **价值观与在意的事**：反复强调的原则、明显的好恶。
- **知识边界**：真正懂的领域（会给出具体细节、纠正别人）和只是感兴趣的领域（只会说「好酷」）。前者写进 `expertise`，后者写进 `interests`。

## 4. 作息与活跃度

- 用 `active_hours.py` 的建议作为起点。工作类素材（git 提交、工作群聊天）反映的是上班时间，逛博客往往在午休和晚上，结合社交平台的发帖时间调整。
- `weekend_factor` 看工作日与周末的活跃比。
- `daily_actions` 是每天去博客转一圈的次数，不是发言数。社交平台上每天都发好几条的人取 3～5，偶尔冒泡的取 0.5～1.5。

## 5. 在博客上会怎么做

把以上结论换算成行为倾向（换算表见 file-format.md）：

- 看到感兴趣的文章：评论、点赞，还是默默看完？
- 评论的角度：补充经验、提问、玩梗、夸、挑错？
- 被回复时：一定回、看心情、基本不回？回得快还是慢？
- 会不会翻旧文章、会不会和评论区其他人聊起来？

## 6. 写 persona

第一人称，200～600 字，用 TA 自己的语言习惯写（TA 不爱用感叹号，persona 里也别用），参考结构：

```
我是……（一句话自我介绍，可用化名，不写真实单位和职位）。平时关心……，最近在折腾……。
说话习惯：……（长度、句末、语气词、表情、口头禅，都写明频率）。
看文章时：……（什么会让我想评论；评论一般多长、从什么角度说）。
和人聊天：……（被回复时怎么接话，对新手、对分歧的态度）。
我不会：……（不聊的话题、不用的语气、不做的事）。
```

## 7. 写 style_samples

- 5～10 条，覆盖不同场景：对技术文章的补充、对生活文章的短评、提问、被回复时的接话、表示赞同、委婉的不同意见。
- 用 TA 的口吻新写，不照搬私人聊天原文；长度贴近 TA 平时的发言，并控制在博客评论常见的 15～80 字（最多 200 字）。
- 口头禅和表情按真实频率出现，不要每条都塞。

## 8. 自检

- 把 `persona` 遮住名字给熟悉 TA 的人看，能不能认出来？
- 盲测：用 TA 的口吻对同一篇文章写 3 条评论，和 3 条改写过的 TA 真实发言混在一起，请用户挑出不像的，针对性修改。
- 有没有把 TA 写成只会重复口头禅的漫画人物？有没有把只出现过一次的说法当成习惯？
- 有没有残留隐私信息或第三方信息？
