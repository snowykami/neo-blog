# 版本历史

文章与独立页面（正文页面）的历史版本：每个版本是正文（草稿）与元信息（标题、描述、封面、slug、分类 / 标签、置顶、私密，页面的导航、版式、全屏）的完整快照，可以预览、恢复为草稿、删除。

- 实现：`internal/model/content_revision.go`、`internal/repo/revision.go`、`internal/service/revision.go`、`internal/controller/revision.go`、定期清理 `internal/tasks/revision_prune.go`
- 前端：编辑器顶栏「版本历史」`web/src/components/tiptap-editor/editor-revision-sheet.tsx`，操作经 `web/src/hooks/use-content-editor.ts`

## 1. 何时记录版本

| 类型 `kind` | 时机 |
| --- | --- |
| `session` 编辑起点 | 打开编辑页（申请编辑会话）时；「放弃本次修改」恢复到它 |
| `autosave` 自动保存 | 保存草稿后，距上一个版本超过 10 分钟时记录一个检查点；外部 AI 工具（API Token）的每次写入都单独记录 |
| `publish` 发布 | 每次发布都记录 |
| `backup` 恢复前备份 | 恢复版本、放弃修改前先备份当前状态，保证这次操作本身也能撤回 |

内容（正文 + 元信息的哈希）与最新版本相同时不重复记录，直接复用最新版本（发布时最新版本不是发布版本的除外）。

## 2. 保留上限与自动清理

- 每篇文章 / 页面最多保留 **N** 个版本，**所有类型一起计数**（包括发布版本——频繁发布不会让版本无限增长）。超出时删除最旧的版本。
- N 在后台「全局配置 → 内容」中设置（配置键 `revision_max_keep`），默认 **50**，允许范围 **10～500**，超出范围时取边界值。
- **受保护的版本始终保留**，即使已不在最新的 N 个之内（因此一篇最多可能有 N + 2 个版本）：
  - `published`：最近的发布版本，即当前发布的内容
  - `latest`：最新的版本，即当前的草稿
  - `base`：当前编辑会话的编辑起点（记在 `edit_sessions.base_revision_id` 上）；会话被顶掉后旧的起点不再受保护
- 清理时机：
  - 每次写入新版本后，立即清理所在的文章 / 页面
  - 服务启动时以及之后每 6 小时，清理所有超出上限的文章 / 页面——处理旧规则（发布版本永久保留）留下的存量数据，以及调低上限后没有再编辑的内容
- 删除文章 / 页面时，其全部版本一并删除。

## 3. 删除版本

- 单个删除：`DELETE /api/v1/{post|page}/p/:id/revisions/:rid`，版本不存在时返回 404。
- 批量删除：`POST /api/v1/{post|page}/p/:id/revisions/batch-delete`，请求体 `{"revision_ids": [1, 2, 3]}`，返回 `{"deleted": 2}`（实际删除的数量）。
  - `revision_ids` 不能为空、不能含 0，一次最多 1000 个，否则返回 400 `invalid_request_parameters`
  - 只删除属于该文章 / 页面的版本，其他目标的版本 ID 被忽略；已不存在的版本视为已删除，不计入数量
- 受保护的版本不能删除：单个删除或批量中含有受保护的版本时返回 400 `revision_protected`，**整批不删除任何版本**。
- 权限与版本历史的其他操作一致：
  - 路由要求登录且角色为编辑者及以上；只有内容的作者或管理员可以删除（管理员可以管理所有文章 / 页面的版本）
  - 需携带当前编辑会话 `X-Edit-Session`：会话已被其他窗口 / 设备接管时返回 409 `edit_session_taken_over`，与恢复版本相同（管理员也需先在编辑页接管）
  - 个人 API Token 不能调用版本接口（路由未开放 Token 权限范围），外部 AI 工具无法删除版本
- 删除版本只影响版本历史，不改动正文草稿与已发布的内容。

## 4. 接口

| 方法 | 路径（`{t}` 为 `post` / `page`） | 说明 |
| --- | --- | --- |
| GET | `/{t}/p/:id/revisions?page=&size=` | 版本列表（新的在前，`size` ≤ 100）；每项带 `protected`（`published` / `latest` / `base`，未受保护时省略），并返回 `total` 与 `max_keep` |
| GET | `/{t}/p/:id/revisions/:rid` | 版本详情（含正文与元信息） |
| POST | `/{t}/p/:id/revisions/:rid/restore` | 把草稿与元信息恢复为该版本（不直接发布），需编辑会话 |
| DELETE | `/{t}/p/:id/revisions/:rid` | 删除单个版本，需编辑会话 |
| POST | `/{t}/p/:id/revisions/batch-delete` | 批量删除版本，需编辑会话 |
| POST | `/{t}/p/:id/discard-draft` | 放弃未发布的修改：草稿恢复为已发布的正文，需编辑会话 |

## 5. 控制台

- 版本历史面板顶部显示版本数与保留上限；列表一次加载 100 个，更多时点「加载更多」。当前发布的版本标有「当前发布」，本次打开编辑器时的版本标有「本次打开」。
- 删除单个版本：在右侧预览底部点「删除」。受保护的版本按钮不可用，并说明原因。
- 批量删除：点列表顶部的「选择」进入选择模式，勾选版本（按住 Shift 点击可连选一段），或用顶部的复选框全选已加载的版本，再点「删除」并确认。受保护的版本显示锁图标，不能勾选。
- 编辑会话被接管（只读）时不能删除。
