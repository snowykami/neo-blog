文章置顶 · 原型

  • 只在首页生效：首页没有分类、标签、搜索筛选时，置顶文章出现在第一页最上方；归档、侧栏的最新 / 热门、搜索、作者页、后台列表都按正常顺序，不受置顶影响。
  • 不占分页名额、不重复：置顶文章另外查询，第一页照常显示 N 篇普通文章；置顶的文章不会在下面的列表里再出现一次。
  • 最多 3 篇，后置顶的在前；可以设到期时间，到期后自动不再置顶（适合公告）。
  • 只有管理员能设置：后端接口、文章设置里的开关、MCP 权限一致；编辑看不到这一项。
  • 数据都是模拟的；界面配色沿用前台默认主题，可切换深色。

编辑器右侧的「文章设置」面板，置顶放在分类、标签下面。打开开关才出现到期时间；首页已满时打开开关，直接在这里取消另一篇，不用跳走。

后台列表按所选方式正常排序，置顶的文章不再浮到最前；标题旁显示置顶标记与到期时间，行菜单里直接置顶 / 取消置顶。「已置顶」筛选用来管理首页上的那几篇。
