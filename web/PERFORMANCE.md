# 前端性能与内存开发守则

本守则面向所有前端功能开发与代码评审（Code Review），旨在保持丰富交互体验的同时，避免首屏包体膨胀、主线程卡顿与长会话内存泄漏。

## 1. 首屏包体与根布局克制

- **服务端组件优先**：默认保持页面与布局为 Server Component，仅在确实需要浏览器 API 或交互状态时添加 `'use client'`，并将客户端边界尽可能下沉到叶子组件。
- **根布局零冗余**：禁止在根布局直接静态 `import` 仅特定页面或交互后才使用的重型模块（如富文本编辑器、图表库、音视频/歌词引擎、图片灯箱/裁剪等），统一使用 `next/dynamic(..., { ssr: false })` 按需拆包。
- **可观测性与第三方脚本异步化**：错误监控、性能追踪、埋点脚本不得阻塞首屏水合；重型 SDK 应推迟至 `requestIdleCallback` 后注册（必要时辅以轻量全局错误队列兜底）。
- **严防桶文件全量导入**：图标库（如 `lucide-react`、`react-icons`）与工具库坚持具名按需导入，严禁在前台代码中使用 `import * as ...`。

## 2. 状态隔离与按需初始化

- **动静分离与读写分离**：高频变化的状态（如播放进度、滚动位置、视口尺寸、拖拽坐标）禁止放入全局 React Context 中广播；优先使用 `useSyncExternalStore` 局部订阅，或通过 `ref` + `requestAnimationFrame` 直接驱动 DOM / CSS 变量。
- **未触发不初始化**：全局悬浮组件或后台能力（如播放器、弹窗、实时桥接）在用户未开启或未触发前，只渲染轻量触发壳子，不提前拉取全量列表数据、不建立长连接（WebSocket / SSE）或启动后台轮询。
- **按需预热**：对动态拆包的交互弹窗，可在触发器的 `onPointerEnter` / `onFocus` 时提前触发一次 `import()` 预热，兼顾首屏体积与点击跟手度。

## 3. DOM 规模与媒体资源控制

- **控制单次交互的 DOM 增量**：单次打开弹层、抽屉或面板，新增 DOM 节点应尽量克制；超过百条的列表（歌单、表格、评论、逐字歌词等）必须采用分页、分批渐进加载或可视区虚拟化，避免一次性全量平铺上千个节点。
- **图片与媒体按需解码**：列表缩略图与头像必须声明合理的 `sizes`、`quality` 或降采样尺寸，避免将原图直接塞进小尺寸容器消耗过高的渲染器物理内存与 GPU 纹理内存。

## 4. 动画、定时器与 GPU 合成层

- **禁止无意义的常驻循环**：`requestAnimationFrame` 与 `setInterval` 必须有明确的启停条件；动画结束、面板收起或页面不可见（`document.hidden` / 离开视口）时，必须立即 `cancelAnimationFrame` 或 `clearInterval`。
- **节制使用毛玻璃**：同屏可见的 `backdrop-filter: blur(...)` 元素尽量控制在少量关键浮层内，避免在长滚动列表卡片中嵌套使用，防止低端设备滚动掉帧。
- **避免强制同步回流（Forced Reflow）**：动画优先使用 `transform` 和 `opacity`；严禁在动画帧或滚动回调中交替读写布局属性（如循环内先改样式再读 `getBoundingClientRect` / `offsetWidth`）。

## 5. 路由缓存与生命周期清理

- **副作用成对清理**：所有 `addEventListener`、`ResizeObserver`、`IntersectionObserver`、`MutationObserver`、WebSocket 连接及 Audio / Canvas 资源，必须在 `useEffect` 清理函数中彻底释放。
- **关注长会话累积**：使用框架路由缓存或 `<Activity>` 保活能力时，需注意连续浏览多个重图文页面后旧 DOM 与已解码图片的驻留问题，避免客户端全局状态或缓存随访问次数只增不减。

## 6. 上线前自检清单

重要前台改动完成后，建议在浏览器 DevTools 中快速核验：

1. **Network**：首页首屏关键 JS 体积与请求数无异常暴涨，重型弹窗未提前打入首屏包。
2. **Performance**：页面静置无后台空转任务，快速滚动无连续掉帧或超过 50ms 的长任务。
3. **Memory**：执行「首页 → 展开交互组件 → 连续跳转数篇文章 → 手动触发 GC」后，DOM 节点数与 JS Heap 无持续异常攀升或 Detached DOM 泄漏。
